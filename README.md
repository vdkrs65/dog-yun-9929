## 什么是联通 AS9929？为什么香港 VPS 圈都在追它

先说人话。中国联通在国内有几套骨干网，普通家宽和企业宽带走的通常是 AS4837 这条"大路"，便宜、容量大，但一到国际出口就容易堵。而 AS9929 是联通内部所谓的"A 网"精品线路，原本主要服务于跨地市专线和企业 IDC，带宽资源更稀缺，路由更短，丢包更低，可以理解成联通版的"CN2 GIA"。

真正让 9929 在 VPS 圈火起来的，是它和 AS10099 搭配后的完整国际链路：

- 去程：AS4837 → AS9929 → AS10099
- 回程：AS10099 → AS9929 → AS4837

这套组合的核心价值在于"三网回程都走联通优化"。也就是说，不管你客户端是电信、联通还是移动，回程都强制塞进联通的精品链路里。对于做跨境业务、远程办公、外贸站的人来说，这种"我不管你从哪来，回去都给你走快车道"的思路，比单纯优化某一网用户体验的方案均衡得多。

非高峰期 AS9929 丢包率通常能压到 1% 以内，延迟比普通 4837 线路低不少。这也是为什么 9929 被很多人称作"除 CN2 GIA 之外最优的回国线路"。
